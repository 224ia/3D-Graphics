# Software 3D Renderer

A simple software 3D renderer written in Java with no external dependencies.

## Features
- Perspective projection
- OBJ model loading
- Camera movement (WASD + mouse)
- Object rotation
- Backface culling
- Diffuse lighting

## Controls
- `WASD` - move camera
- `Q/E` - move up/down
- `Mouse` - look around

## How to run
1. Clone the repository
2. Open in your IDE
3. Run `Main.java`

## Dependencies
- JOML (Java OpenGL Math Library) - included in lib/
